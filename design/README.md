# design/ — historical archive

Superseded specs, kept for the record under `archive/`. Each opens with a
"Historical" banner. The code and `docs/design/` describe the current design:
the catalog schema, for one, is `src/statcatlib/store/schema.py`, not
`archive/statcatlib_design_spec_final.md`.

| file | what it was |
|---|---|
| `archive/statcatlib_design_spec_final.md` | The original catalog engine design |
| `archive/storage_schema_spec.md` | The original sdmxlib storage schema design, now sdmxlib's to document |
| `archive/naming_proposal.md` | How the names in `docs/design/products-editions-inventory.md` were chosen |
